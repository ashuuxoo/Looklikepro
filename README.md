## ✨ Features

- 🔎 Quick phone number search
- 👤 Caller name when available
- 📞 Phone number display
- 📍 Location / circle information when available
- 🎂 Additional information when available
- 🖼️ Profile image when available
- ⚡ Clean and responsive interface
- 🌙 Modern dark UI
- 📱 Native Android app
- 🔐 No unnecessary phone permissions

## 🚀 How It Works

```text
Enter phone number
        ↓
      Search
        ↓
   Lookup service
        ↓
   Result received
        ↓
  Caller information
```

## 📦 Build APK

The project includes a GitHub Actions workflow that automatically builds a debug APK.

```text
GitHub → Actions → Build APK → Artifact → Install
```

No PC or Android Studio is required to download an APK from a completed GitHub Actions build.

## 🔐 Privacy

Phone numbers entered for lookup are sent to the configured third-party lookup service to retrieve available information. Avoid entering sensitive numbers if you do not want them sent to that service.

The app does not need contacts, call-log, SMS, microphone, or location permissions for its basic lookup feature.
